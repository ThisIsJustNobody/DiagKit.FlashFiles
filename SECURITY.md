# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of `DiagKit.FlashFiles`.

## Reporting A Vulnerability

Please do not disclose suspected vulnerabilities publicly before they are reviewed.

Report issues privately through the repository security advisory flow when available, or contact the maintainer associated with the NuGet package metadata.

Include:

- A short description of the issue.
- A minimal reproduction, sample input, or affected API.
- Any known impact on parsing, memory use, file handling, or generated output.

The maintainer will review the report, confirm the impact, and coordinate a fix or disclosure timeline.
